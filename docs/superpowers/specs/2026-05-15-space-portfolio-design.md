# Space Portfolio Design

## Goal

Build an interactive one-page portfolio CV for Rafly Maulannasir that presents him as a professional Web and Machine Learning Developer with additional strengths in IT engineering, game development, AI imagery, vibe coding, and game streaming.

## Direction

The portfolio uses a space mission control concept. The first impression should feel like entering a polished command interface for a developer who can build, automate, experiment, and present work confidently to clients around the world.

## Structure

1. Hero: name, main profession, short positioning copy, primary calls to action, animated space scene, and quick role chips.
2. About: short professional summary with trust-oriented highlights.
3. Expertise: skill areas shown as system modules.
4. Projects: editable mission log cards with placeholder projects.
5. Timeline: experience and learning trajectory as orbital checkpoints.
6. Creative Tech: AI imagery, vibe coding, and streaming presence.
7. Contact: transmission-style contact panel with placeholders for links.

## Visual System

- Dark space background with animated stars, soft nebula gradients, and subtle orbital lines.
- Cyan, violet, and gold accents balanced against white text.
- Glass-like surfaces, fine borders, restrained shadows, and sharp professional spacing.
- Smooth reveal animations, hover lift states, and cursor-responsive motion.
- No dependency-heavy framework; static HTML, CSS, and JavaScript for easy editing.

## Content Rules

The site includes confirmed content:

- Name: Rafly Maulannasir
- Main role: Web & Machine Learning Developer
- Secondary capabilities: IT Engineer, Game Developer, AI Imagery, Vibe Coding, Game Streamer

Unconfirmed details such as email, social links, real projects, education, and employment history remain clearly marked as editable placeholders.

## Acceptance

The first version is accepted when it opens locally as a polished interactive portfolio, has working navigation, animations, responsive layout, and easy-to-edit placeholders for missing personal data.
